# StudyFlow в резюме

## Готовое описание

**StudyFlow — учебный проект, REST API платформы учебных заданий.**
[GitHub](https://github.com/daytimeserg0/study_flow)

- Разработал API курсов, зачисления студентов, публикации заданий, сдачи решений
  и оценивания. Реализовал JWT-аутентификацию, роли преподавателя и студента,
  проверку владения объектами и изоляцию работ студентов.
- Обеспечил согласованность отправки и проверки работ через транзакции,
  блокировки строк PostgreSQL и ограничения БД. Добавил расчёт прогресса
  SQL-агрегатами, поиск, фильтры и пагинацию; проверил отсутствие N+1 тестами.
- Написал API-тесты и проверки конкурентных запросов. Настроил Docker Compose,
  документацию OpenAPI/Swagger и GitHub Actions для линтинга, тестов с покрытием,
  проверки миграций и сборки образа.

**Стек:** Python 3.13, Django 5.2, Django REST Framework, PostgreSQL 18,
Simple JWT, drf-spectacular, pytest, pytest-django, pytest-cov, Ruff,
Docker Compose, GitHub Actions.

## Что объяснить на собеседовании

| Тема | Пример из проекта |
| --- | --- |
| Модель данных | Зачем нужна отдельная `Enrollment`, почему одна работа на пару задание–студент и одна оценка на работу |
| Аутентификация и права | Чем JWT отличается от разрешения на объект; почему роль читается из БД и фильтрация queryset обязательна для списков |
| Безопасность API | Как проверяются вложенные URL, скрываются чужие работы и отклоняются подменённые владельцы и служебные поля |
| Транзакции | Как порядок блокировок задания, решения и оценки защищает от одновременной отправки, редактирования и проверки |
| Ограничения БД | Какие правила проверяет `CHECK`, что защищает `UNIQUE` и почему сравнение оценки с максимумом задания требует логики приложения |
| SQL и производительность | Как считается прогресс, зачем `select_related`, чем число SQL-запросов отличается от скорости обработки больших объёмов данных |
| Тестирование и CI | Как проверяются права, граничные значения и гонки; зачем тестам PostgreSQL и почему процент покрытия не доказывает отсутствие ошибок |
| Компромиссы | Почему проверенная работа закрыта для редактирования, что теряется без истории попыток и как блокировка задания ограничивает параллельную запись |
